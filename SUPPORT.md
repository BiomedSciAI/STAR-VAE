# Support

Use [GitHub Issues](https://github.com/BiomedSciAI/STAR-VAE/issues) for
reproducible installation problems, documentation defects, and software bugs.
Include the operating system, Python version, installation command, exact CLI,
relevant traceback, and whether checkpoints, datasets, CUDA, or external tools
were involved. Remove private paths, credentials, proprietary data, and large
logs before posting.

Questions about obtaining or licensing PubChem, MOSES, GuacaMol, B3DB,
Tartarus, ChEMBL, QVina, Open Babel, or third-party baseline assets should be
directed to their respective providers. This project does not redistribute or
provide support guarantees for those resources.

For the publisher-supplied STAR-VAE checkpoint archive, report missing license
notices, provenance defects, or questions about institutional distribution-rights
to the maintainers rather than to dataset providers. The checkpoint archive is
provided under OpenMDW-1.0. Datasets are separate and are not redistributed.

Do not report security vulnerabilities publicly. Follow [SECURITY.md](SECURITY.md).
We maintain this research software on a best-effort basis. We do not offer a
service level or a guaranteed response time.
